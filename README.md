# Maximum Salary

A Python solution that arranges individual digits into the largest possible number. For example, `[9, 8, 9, 6, 1]` becomes **99861**.

[Max_Salary.py](Max_Salary.py) repeatedly selects the largest remaining digit, appends it to the result, and removes it from the list. The result is returned as a string, and the input list is emptied.

The program uses a sample list of digits from 0 to 9 and prints the result.
